# 🌦 Weather Dashboard

A modern, responsive weather dashboard built using ReactJS and Open-Meteo API.

---

## 🚀 Features

- 📍 GPS-based location detection
- 🌡 Real-time weather data
- 📊 Hourly weather charts
- 📅 Historical data analysis
- 📱 Fully responsive design

---

## 🛠 Tech Stack

- ReactJS (Vite)
- Tailwind CSS
- Recharts
- Axios
